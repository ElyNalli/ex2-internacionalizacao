# ex2-internacionalizacao# EX2 - Internacionalização do Sistema Web

Fatec Americana - Prof. José William Pinto Gomes

## Como executar

Use a extensão Live Server do VS Code (botão direito em `index.html` >
Open with Live Server). Não abra com dois cliques, pois o navegador bloqueia
a leitura dos arquivos de tradução.

## Idiomas

Português (pt-BR) e Inglês (en).

## Link publicado

https://ElyNalli.github.io/ex2-internacionalizacao/

## Uso de IA

Utilizei o Claude como apoio para entender como estruturar o sistema de internacionalização (i18n.js) e organizar os arquivos JSON responsáveis pelas traduções.

Também, por sugestão da ferramenta, utilizei a API Intl para a formatação de datas, números e moedas de acordo com a localização selecionada.

Após estudar as sugestões, li, testei e adaptei o código às necessidades do projeto. Atualmente, consigo explicar seu funcionamento e compreender a lógica utilizada na implementação.
